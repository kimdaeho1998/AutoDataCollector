# Sales Data Collector

Windows용 매출 데이터 수집 도구의 일반화된 소스입니다. 지정한 기간과 매장의 매출을 조회해,
원본 Excel 템플릿을 복사한 결과 파일에 `건수`와 `총매출`만 기록합니다.

## 로컬 설정

운영 접속 정보와 브랜드 식별자는 저장소에 포함하지 않습니다. `.env.example`을 참고하여
다음 값을 운영 PC의 환경변수로만 설정합니다.

```text
COLLECTOR_BASE_URL
COLLECTOR_BRAND_IDX
COLLECTOR_BRAND_NAME
COLLECTOR_BRAND_PREFIX
```

계정 ID와 비밀번호는 실행 시 입력하며 코드, 환경 파일, 로그에 저장하지 않습니다.

## 수집 규칙

- 기준 페이지의 `매출건수`, `총 매출`만 기록값으로 사용합니다.
- 데이터가 없는 매장/일자는 두 항목에 `-`를 기록합니다.
- 템플릿 A열 구분이 `중단` 또는 `폐점`이면 원격 조회를 생략하고 두 항목에 `-`를 기록합니다.
- 기존 입력값은 최신 수집값으로 덮어쓰되 수식 셀은 변경하지 않습니다.
- 원본 템플릿을 직접 수정하지 않고 복사본만 저장합니다.

## 개발 환경

Python 3.13 이상과 Microsoft Excel 데스크톱 앱이 필요합니다.

```powershell
python -m pip install -e .
python main.py --help
```

Excel 기록은 원본 서식과 수식을 보존하기 위해 Windows Excel COM 자동화를 사용합니다.

## 보안 및 배포

- Git에는 소스와 일반화된 문서만 보관합니다.
- `.gitignore`는 테스트, Excel 원본/결과, 로그, 빌드 산출물, `*.exe`, 로컬 환경 파일을 제외합니다.
- 실제 응답 HTML, 네트워크 내보내기(HAR), 캡처 이미지, 고객·매장 정보, 계정정보는 커밋하지 않습니다.
- 운영용 실행 파일은 Git이 아닌 접근 제어된 사내 배포 공간에서 관리합니다.
- 저장소는 **Private**으로 유지합니다.
